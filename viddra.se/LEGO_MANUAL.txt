PART 2 — SAVE CURRENT VIDDRA AS /se/
========================================================
You have two ways:

-------------------------
OPTION A (RECOMMENDED): Use subdomain instead of /se/
-------------------------
This avoids path issues.

A1) Create subdomain: se.viddra.se
A2) Point subdomain document root to: public_html_se/  (or any folder you choose)
A3) Move/copy your current site from public_html/ into public_html_se/
A4) Test: https://se.viddra.se/

If you still want /se/ as a URL, you can later do a redirect /se -> https://se.viddra.se/

-------------------------
OPTION B (YOUR REQUEST): Use /se/ folder
-------------------------
B1) In public_html/, create a folder named: se
B2) Move ALL your current site files/folders into /public_html/se/
    - This includes index.php, assets, css, js, etc.
B3) Test: https://viddra.se/se/

If it looks broken (missing CSS/images):
B4) The old site likely uses absolute paths. Fix by:
    - Searching the old code for: href="/", src="/", url(/)
    - Changing them to: href="/se/", src="/se/", url(/se/)
    - OR add in old site's <head>: <base href="/se/">
